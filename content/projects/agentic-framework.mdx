## Overview

Agentic Framework is the foundation library extracted from the Agentic Browser project. It provides reusable patterns for building multi-agent AI systems, including agent coordination, shared memory, tool management, and safety guardrails. Think of it as a toolkit for constructing your own agent orchestration systems.

## Key Features

- **Agent Base Classes**: Abstract classes for building specialized agents with consistent interfaces.
- **Coordination Patterns**: Pre-built patterns for agent communication and task delegation.
- **Memory Management**: Shared and per-agent memory with persistence options.
- **Tool Registry**: Centralized tool management with access control and logging.
- **Safety Guardrails**: Configurable limits on agent actions and resource usage.
- **State Management**: LangGraph-based state machines for complex agent workflows.

## Technical Architecture

The framework is organized into composable modules that can be used independently or together. The core module provides agent base classes and interfaces, while extension modules add specific capabilities like memory persistence or advanced coordination.

Module structure:
- **Core**: Agent base classes, message types, and core interfaces.
- **Coordination**: Patterns for multi-agent communication and task routing.
- **Memory**: Short-term, long-term, and shared memory implementations.
- **Tools**: Tool registry, access control, and execution logging.
- **Safety**: Rate limiting, action filtering, and approval workflows.

## Technology Stack

- **Core**: Python 3.11+ with type hints throughout
- **Orchestration**: LangGraph for state machine management
- **LLM Integration**: LangChain for provider abstraction
- **Storage**: Pluggable backends (SQLite, PostgreSQL, Redis)
- **Serialization**: Pydantic for data validation and serialization

## Current Status

Active development as part of the Agentic Browser project. Core patterns are stable and in use. Currently expanding the coordination patterns and improving documentation for external use.
