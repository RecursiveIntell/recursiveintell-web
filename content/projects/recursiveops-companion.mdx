## Overview

RecursiveOps Companion is the desktop counterpart to the RecursiveOps server management platform. Built with Tauri and Rust, it provides quick access to server status, alerts, and common operations directly from your system tray, with full offline support when connectivity is limited.

## Key Features

- **System Tray Integration**: Monitor server health without opening a browser.
- **Offline Support**: Queue operations when offline, sync when connectivity returns.
- **Secure Credential Storage**: OS keychain integration for safe token management.
- **Quick Actions**: One-click access to common server operations.
- **Native Notifications**: System-level alerts for critical server events.
- **Cross-Platform**: Runs on Linux, macOS, and Windows.

## Technical Architecture

The companion app uses Tauri's Rust backend for system integration and security-sensitive operations, with a Svelte frontend for the UI. Communication with the RecursiveOps backend happens through a REST API with WebSocket connections for real-time updates.

Architecture highlights:
- **Rust Backend**: Handles keychain access, system tray, and native notifications.
- **Svelte Frontend**: Lightweight reactive UI embedded in the native window.
- **Offline Queue**: SQLite-backed queue for operations made while offline.
- **Secure Storage**: Platform-specific keychain integration (Secret Service, Keychain, Credential Manager).

## Technology Stack

- **Framework**: Tauri 2.0 for native desktop packaging
- **Backend**: Rust for system integration and security
- **Frontend**: Svelte with TypeScript for reactive UI
- **Storage**: SQLite for local data, OS keychain for credentials
- **Communication**: REST API client with WebSocket for real-time updates

## Current Status

Active development with core functionality complete. System tray, notifications, and secure credential storage are fully implemented. Currently improving offline sync reliability and adding support for more server operations.
