## Overview

Context Weaver is a RAG (Retrieval-Augmented Generation) system designed for complex, multi-source contexts. Unlike basic vector search, it understands the structure and relationships within your data—code dependencies, document hierarchies, conversation threads—and weaves them into coherent context for LLM queries.

## The Challenge

Standard RAG pipelines treat documents as flat chunks of text. This works for simple Q&A but fails when:

- Code files depend on each other (you need the imports, not just the function)
- Documents reference other documents (the answer spans multiple files)
- Conversations build on previous exchanges (context is cumulative)

Context Weaver solves this by building a graph of relationships and traversing it intelligently during retrieval.

## Architecture

**Ingestion Layer** — Parses source material (code, markdown, PDFs, Slack exports) and extracts both content and structure. Uses language-specific parsers for code to understand imports, function calls, and class hierarchies.

**Relationship Graph** — A property graph stored in Neo4j that captures connections between content nodes. Edges represent relationships like "imports," "references," "replies-to," and "defines."

**Hybrid Retriever** — Combines dense vector search (for semantic similarity) with graph traversal (for structural relationships). Returns not just relevant chunks but their connected context.

**Context Assembler** — Takes retrieved nodes and assembles them into a coherent prompt, respecting token limits while maximizing information density. Uses summarization for less relevant nodes.

## Key Features

- **Code-aware chunking** — Splits at function/class boundaries, preserves imports and type definitions
- **Cross-file context** — Automatically pulls in related files when answering code questions
- **Conversation threading** — Maintains context across multi-turn dialogues with automatic summarization
- **Source attribution** — Every piece of context is traceable back to its source with line numbers

## Integration

Context Weaver exposes a simple API:

```python
from context_weaver import Weaver

weaver = Weaver(
    sources=["./src", "./docs"],
    model="claude-3-5-sonnet"
)

response = weaver.query(
    "How does the authentication middleware validate tokens?",
    max_context_tokens=8000
)

print(response.answer)
print(response.sources)  # Links to relevant files/lines
```

## Technical Stack

- **Core**: Python with async support
- **Embeddings**: Voyage AI for code, OpenAI for general text
- **Graph**: Neo4j with custom Cypher queries
- **Vector Store**: Pinecone for scalable similarity search
- **LLM**: Anthropic Claude API with streaming responses

## Results

Tested against standard RAG on a 500k LOC codebase:

- Answer accuracy: 73% → 89% (human evaluation)
- Relevant context inclusion: 45% → 82%
- Hallucination rate: 12% → 3%
