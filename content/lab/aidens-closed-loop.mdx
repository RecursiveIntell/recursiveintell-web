## Overview

This is a live, interactive demo page for the AiDENs closed-loop self-learning AI system. It shows real metrics from a live loop run with gemma4:31b-cloud, captured facts from the autonomous namespace, the 8 mission types, and an honest comparison against other systems.

## The Demo

The demo page is a self-contained HTML file with embedded CSS — no external dependencies. It shows:

- Live KB metrics (7,228 facts, 15,413 chunks, 877 documents)
- The closed loop diagram (6 steps: Detect → Generate → Execute → Capture → Evaluate → Feedback)
- Live run metrics from a 5-iteration test (100% success rate, 9 facts captured)
- Real captured facts from the autonomous namespace
- All 8 mission cards with priorities and frequencies
- Comparison table vs Zep/Graphiti, Letta/MemGPT, AutoGPT, MemRL
- Architecture section with the 3 main crates
