Evidence vocabulary

  • SourceTests the audited checkout and exact command scope.
  • PackageRequires packed-crate dependency and clean-install parity.
  • LiveRequires artifact hashes, selected profile, and canary verification.
  • ReceiptRecords execution evidence; it is not correctness certification.

Release truth gate

  • BindDefault-branch commit, artifact digest, CI run, configuration, and public claims.
  • RefuseStale status, missing sources, unsupported benchmark claims, or incomplete closures.
  • EmitA terminal certificate, omission receipt, and human-readable evidence pack.
  • DogfoodUse the stack’s own receipts and ledgers to certify the stack itself.

What this can demonstrate

Which execution path was recorded, whether cache was bypassed, exactness evidence, state view, and whether degradations were present.

What it cannot demonstrate

That the result is factually true, that a later assertion is authorized, that an action is permitted, or that the full system is secure.

Receipts prove recorded evidence—not total correctness.

09 · 180-day sequence

Certify first. Then compound.

The highest-leverage sequence begins by repairing release truth, then uses that discipline to ship an inspectable agent and a user-facing memory product.

Days 0–30

Restore certification

Make the default-branch release boundary terminal, reproducible, and claim-bound.

  • Fix failed CI lanes and formatting
  • Run post-merge default-branch gates
  • Bind artifacts, digests, configuration, and claims
Gate: one green release certificate
Days 31–60

Dogfood Truth Gate

Turn the internal evidence discipline into an adoptable release-control product.

  • Reject stale or unbound status
  • Emit omission receipts
  • Generate a human-readable evidence pack
Gate: the stack certifies itself
Days 61–120

Witnessed coding agent

Compose memory, tools, policy, claims, and replay around representative coding work.

  • Typed failure stays failure
  • Tool calls and claims share trace identity
  • Replay reconstructs the evidence graph
Gate: ten stable replay tasks
Days 121–180

Operator Memory OS

Make temporal truth, contradiction, provenance, and forgetting legible to an operator.

  • Longitudinal memory evaluation
  • Update and abstention targets
  • Selective-forgetting receipts
Gate: published memory scorecard
