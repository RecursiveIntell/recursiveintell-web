Evidence vocabulary

What this can demonstrate

Which execution path was recorded, whether cache was bypassed, exactness evidence, state view, and whether degradations were present.

What this cannot demonstrate

That the result is factually true, that a later assertion is authorized, that an action is permitted, or that the full system is secure.

Fields are drawn from the current witnessed-search contract; identifiers and content are deliberately redacted.
