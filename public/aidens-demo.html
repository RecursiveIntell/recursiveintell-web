AiDENs

A closed-loop self-learning AI that audits its own knowledge graph, detects gaps, generates tasks, executes them via LLM, captures results as provenance-attributed facts, and evaluates fact quality — all local-first, all autonomous.

TL;DR — The memory system powering this demo — semantic-memory — is available now as a Rust crate and MCP server. It's a typed knowledge graph with provenance, bitemporal search, contradiction detection, and 48 MCP tools. AiDENs is the autonomous loop on top of it, coming soon. This demo shows what happens when you close the loop: the system audits its own knowledge graph, detects gaps, and learns autonomously. 7,228 facts, 8 mission types, 100% task success rate.

00The Memory System — Available Now

The knowledge graph that powers AiDENs is a standalone Rust crate and MCP server you can use today. It works with Claude Desktop, Cursor, Hermes, and any MCP-compatible client.

semantic-memory (Rust crate)

A typed knowledge graph with 7,000+ facts, heterogeneous edges (semantic / temporal / causal / entity), bitemporal search, provenance semiring, contradiction detection via decoder syndrome analysis, factor graph belief propagation, and RL-trained adaptive retrieval routing.

  • Provenance-first: every fact has source attribution, confidence, and a receipt
  • Bitemporal: the system knows what it believed on date X and can trace how beliefs changed
  • Self-correcting: facts can be superseded when better evidence arrives
  • Adaptive routing: RL-trained retrieval learns which stages (BM25, vector, graph, decoder, discord) help which query types
  • Auto-management: integrity checks, vacuum, re-embedding, reconciliation — all via HTTP endpoints
crates.io → GitHub →

semantic-memory-mcp (MCP server)

48 MCP tools wrapping semantic-memory, plus 15 HTTP endpoints for high-performance hook integration. Works with Claude Desktop, Cursor, Hermes, and any MCP-compatible client. Tool profile gating (lean / standard / full) keeps the tool list manageable.

  • 34 daily-use tools (search, graph traversal, fact CRUD, claim verification) in lean profile
  • 14 admin/audit tools (vacuum, re-embed, reconcile, bitemporal queries, import) in standard/full
  • 15 HTTP endpoints for hooks and scripts (search, search-routed, discord, maintenance, record-outcome)
  • RL routing persistence: every search outcome feeds the adaptive retrieval policy

06Architecture

Built in Rust. 56K LOC across 36 crates. 506 tests + 162 autonomous tests. Runs entirely local-first with Ollama.

aidens-autonomous

The closed-loop brain. 8K LOC, 162 tests.

  • gap_detector.rs — 7 gap types: MissingContext, MissingLink, StaleFact, ContradictionGap, DuplicateFact, StaleByDate, LowQualityFact
  • missions.rs — 8 mission types with adaptive priority scheduling
  • executor.rs — PlanActVerifyLoopV1 with Ollama provider, system prompt, RL feedback
  • capture.rs — Sentence-level fact extraction with per-sentence confidence
  • evaluation.rs — Content quality scoring: numbers, dates, proper nouns, tech terms, coherence
  • loop_driver.rs — Main loop with safe mode, attempted gaps tracking, mission scheduling

semantic-memory

The knowledge graph. 7000+ facts, typed edges (semantic/temporal/causal/entity), bitemporal search, contradiction detection, factor graph belief propagation.

aidens-tui

Terminal UI with 4 panels: memory stats, loop state, queue, activity log. ratatui + crossterm.

07Try It Yourself

The entire system runs locally. You need Rust, Ollama, and about 5 minutes.

Quickstart

Install Ollama and pull a model
Any Ollama-compatible model works. A 3B+ model is recommended for quality output.
curl -fsSL https://ollama.com/install.sh | sh
ollama pull granite4.1:8b
Clone the AiDENs workspace
The workspace includes all 36 crates — the autonomous loop, semantic-memory, TUI, and more.
git clone https://github.com/RecursiveIntell/AiDENs.git
cd AiDENs
Start the semantic-memory HTTP server
The knowledge graph backend. Runs on port 1738 with the candle embedder.
cargo install semantic-memory-mcp
semantic-memory-mcp --memory-dir ~/.hermes/sm.db --embedder candle --http-port 1738 --http-only --tool-profile lean
Run the autonomous loop (headless)
Runs the closed loop for 10 iterations, detecting gaps and capturing facts.
cargo build -p aidens-cli --release
./target/release/aidens-cli autonomous \
  --memory-dir ~/.hermes/sm.db \
  --queue-dir /tmp/aidens-queue \
  --ollama-url http://127.0.0.1:11434 \
  --ollama-model granite4.1:8b \
  --http-base-url http://127.0.0.1:1738 \
  --max-iterations 10
Or: launch the TUI for a live view
4-panel terminal UI showing memory stats, loop state, queue, and activity log in real time.
./scripts/run-tui.sh granite4.1:8b http://127.0.0.1:11434
