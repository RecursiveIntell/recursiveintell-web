Before you start

The first successful recall is step six.

Installation proves the components can start. It does not prove useful memory. A new store is empty by design; ingest or deliberately capture facts before judging recall.

Prerequisites Required Git, Python 3, and a Rust toolchain with cargo. Host Install the agent host you intend to use before applying its kit. 01 · RecommendedClaude Code · hook tier

Claude Code plugin

Use Claude Code’s plugin marketplace path. The kit installs lifecycle hooks, MCP configuration, memory commands, doctor checks, ingestion, and evidence workflows.

/plugin marketplace add RecursiveIntell/agent-memory-kits
/plugin install semantic-memory@semantic-memory-kit
/memory-setup
  1. RestartRestart Claude Code once so the new hooks load.
  2. IngestFrom a real project, run /memory-ingest ..
  3. VerifyRun the doctor, then ask about a concrete symbol or decision from that repository.

Expected behavior An empty store returns no memory and never blocks a prompt. The product is the compounding curve, not the first session.

02 · Hook tierCodex CLI

Codex CLI plugin

Add the repository’s Codex marketplace, then install the semantic-memory kit. The current kit includes Python hooks, prompts, skills, MCP configuration, doctors, ingestion, and audit helpers.

git clone https://github.com/RecursiveIntell/agent-memory-kits
cd agent-memory-kits
codex plugin marketplace add ./codex
codex plugin add semantic-memory@semantic-memory-codex-kit
  1. Canonical storeUse one memory directory across projects that should share recall.
  2. Single ownerLet one process own any warm HTTP port to avoid competing servers.
  3. VerifyRun the Codex doctor, ingest a repository, restart if required, and test recall.

Support boundary Codex is documented as a hook-capable reference integration. Inspect installed hooks and active MCP configuration rather than assuming they loaded.

03 · Plugin + MCPHermes Agent

Hermes plugin and MCP server

Copy the Hermes plugin, enable it, register semantic-memory as an MCP server, and test the active connection.

git clone https://github.com/RecursiveIntell/agent-memory-kits
cd agent-memory-kits
cp -R hermes "$HOME/.hermes/plugins/semantic-memory-mcp"
hermes plugins enable semantic-memory-mcp
hermes mcp add semantic_memory \
  --command semantic-memory-mcp \
  --args --memory-dir "$HOME/.local/share/semantic-memory" --tool-profile agent
hermes mcp configure semantic_memory
hermes mcp list
hermes mcp test semantic_memory
  1. Argument order--args consumes every remaining argument and must come last.
  2. RestartRestart Hermes after installing or changing plugin code.
  3. VerifyConfirm the MCP listing and test pass, then ingest before judging recall.

Configuration boundary Use the plugin and MCP commands as the primary path. Do not rely on hand-edited legacy configuration.

04 · Rules tierCursor · Cline · Roo Code · Windsurf · Continue · OpenCode

MCP plus host-native rules

These hosts receive MCP tools plus explicit rule/context files. Cursor is shown; replace the directory with the kit for your supported host.

git clone https://github.com/RecursiveIntell/agent-memory-kits
cd agent-memory-kits
cursor/scripts/setup.sh --write-project /path/to/project
shared/scripts/doctor-all.py --deep
  1. Select hostUse cursor, cline, roo-code, windsurf, continue, or opencode.
  2. Write configLet the setup script create the host’s MCP and rule/context files.
  3. VerifyRun the deep shared doctor and inspect the exact files your host will load.

Honest tiering A rules file is not a hidden pre-prompt, session, or compaction hook. The host or agent must invoke the MCP workflow.

05 · ProtocolDirect MCP client

Semantic Memory MCP

Install the published binary, point it at one canonical memory directory, and begin with the bounded agent profile.

cargo install semantic-memory-mcp --locked --version '=0.5.4'
semantic-memory-mcp \
  --memory-dir "$HOME/.local/share/semantic-memory" \
  --tool-profile agent
  1. PackageVersion 0.5.4 matches the current repository manifest checked July 16, 2026.
  2. DiscoverUse tools/list as truth for this binary, feature set, and runtime profile.
  3. WitnessRun a witnessed search and inspect the receipt, state view, backend, and degradations.

Release boundary Repository version parity is not a clean-machine package receipt. Treat published-package and source evidence as separate scopes.

Semantic Memory library

Add the crate, then follow the deterministic MockEmbedder quick start before selecting a production embedder or optional research feature.

cargo add semantic-memory@0.5.10
# begin with the deterministic MockEmbedder quick start
# before selecting a production embedder
  1. Deterministic firstProve storage, FTS, fusion, and state behavior without a model/network variable.

Speed up the curve

Populate useful memory on day one.

Install the three companion services, install the host kit, ingest repositories you use, restart the host, and work normally. Receipts stay inspectable.

# Companion MCP services
cargo install semantic-memory-mcp context-governor claim-ledger

# Claude Code host kit
/plugin marketplace add RecursiveIntell/agent-memory-kits
/plugin install semantic-memory@semantic-memory-kit
/memory-setup

# Ingest work you actually use
/memory-ingest .
/memory-ingest ../other-repo

# Restart the host so hooks load, then work normally.

Local-first, not magically isolated Hosted storage is not required. First-run model downloads and a remotely configured Ollama endpoint are explicit network boundaries; a local store is not automatically encrypted.
